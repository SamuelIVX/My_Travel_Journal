# My Travel Journal

A small React travel-journal SPA that renders destination cards (Mount Fuji, Sydney Opera House, Geirangerfjord) with image, title, location, Google Maps link, dates, and description.

Bootstrapped with [Create React App](https://github.com/facebook/create-react-app) (React 18). Follows the freeCodeCamp React travel-journal tutorial — components, props, and `.map()` over hardcoded destination data.

**Live:** https://samuelivx.github.io/My_Travel_Journal/

## Commands

```bash
npm install && npm start                 # local dev → http://localhost:3000
CI=true npm test -- --watchAll=false     # smoke tests
npm run lint                             # ESLint on src/
npm run build                            # production build → build/
```
